Perguntas e Respostas sobre Git

1 - O que são operações de "Commit", "Push" e "Pop" efetuadas num repositório?

Resposta à questão 1:

  • Commit: Gravar as alterações no repositório com uma mensagem descritiva.
  • Push: Enviar os commits locais para o repositório remoto (servidor).
  • Pop: Repor alterações guardadas temporariamente.

2 – Quais são as vantagens de usar Branchs num repositório git?

Resposta à questão 2:

As vantagens de usar branches são:

  • Trabalhar em funcionalidades diferentes em paralelo
  • Isolar alterações sem afetar o código principal
  • Facilitar revisão de código antes de juntar
  • Permitir correção de erros sem interromper desenvolvimento
  • Organizar e controlar versões do projeto

3 – Nos Merges de conteúdos resultantes de um "Pop" podem resultar em conflitos. Em que consistem e como podem ser resolvidos esses conflitos?

Resposta à questão 3:

Conflitos ocorrem quando as mesmas linhas de código foram alteradas de formas diferentes em dois branches que tentamos juntar. Para resolver, o Git marca as linhas conflituosas no ficheiro, escolhe manualmente qual versão manter (a do branch atual ou a do stash), remove os marcadores de conflito e faz um novo commit para finalizar a combinação. O ficheiro mostra claramente onde estão os conflitos, permitindo decidir que código manter.

4 – "Clone" e "Fork" são formas diferentes de replicar um repositório Git. Quais as diferenças entre eles?

Resposta à questão 4:

Clone cria uma cópia local do repositório no computador e mantém ligação ao repositório original, enquanto o fork cria uma cópia independente do repositório na minha conta (geralmente em plataformas como GitHub) ficando completamente separado do original.

A diferença principal é que clone é local enquanto fork é remoto e independente.
